# Design System

## Typography

- Base font: 16–18px
- Headings: Bold, high contrast

## Colors

- High contrast
- Accessible (WCAG 2.1 AA)

## Buttons

- Min height: 44px
- Clear labels
- No icon-only buttons

## Cards

- Clean spacing
- Shadow-sm
- Rounded-lg

## Accessibility

- Focus states visible
- Keyboard navigable
