# Vision — TRYCON BUILT CARE Client Dashboard

## Purpose

Build a secure, responsive web-based client dashboard for TRYCON BUILT CARE to manage client contracts efficiently.

## Target Users

- Admin (full access)
- Normal User (restricted access)
- Age group focus: 40+

## Core Objectives

- Simple contract tracking
- Secure role-based access
- Clean and intuitive UI
- Fully responsive (mobile + desktop)
- Free-forever infrastructure

## Non-Goals

- No heavy file storage
- No real-time chat
- No microservices architecture
- No unnecessary frameworks

## Constraints

- Supabase Free Tier
- Vercel Free Tier
- WCAG 2.1 accessibility compliance
